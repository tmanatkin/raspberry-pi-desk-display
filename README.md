# Raspberry Pi Desk Display

A small always-on desk display running on a Raspberry Pi.

![Raspberry Pi](https://img.shields.io/badge/Raspberry%20Pi-222222?style=for-the-badge&logo=raspberrypi&logoColor=A22846)
![Flask](https://img.shields.io/badge/Flask-222222?style=for-the-badge&logo=flask)
![Python](https://img.shields.io/badge/Python-222222?style=for-the-badge&logo=python)

- Fullscreen pywebview window with a local Flask server
- Hardware setup uses a display screen and rotary encoder
